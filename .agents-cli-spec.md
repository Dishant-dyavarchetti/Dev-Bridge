# Agent Spec: DevBridge

## Overview
DevBridge is an AI-powered mentorship platform that helps developers confidently navigate the open-source contribution journey. The backend uses a multi-agent GraphFlow orchestration to guide users through discovering projects, understanding architecture, and preparing pull requests.

## Architecture
- **Orchestration**: GraphFlow state machine (adk 2.0) coordinating specialized reasoning agents.
- **Agents**: Planner Agent, Repository Analysis Agent, Contribution Mentor, Issue Recommendation, Response Composer.
- **State**: Shared `DevBridgeState` containing RepositoryState, ContributionState, IssueState, and ProgressState.

## Example Use Cases
- User wants to find a project: Planner routes to Repository Discovery.
- User selects a project: Repository Analysis agent explains architecture and setup.
- User wants to start contributing: Contribution Mentor suggests beginner issues and explains the workflow.

## Tools Required
- GitHub APIs (search repositories, read issues, PRs)
- Repository Analysis (parse contribution guidelines)
- Database (persist User Progress / ProgressState)

## Constraints & Safety Rules
- The agent must **Teach, Don't Replace**. It should explain concepts rather than simply producing answers.
- The agent must **NOT** automatically write complete feature implementations.
- The agent must **NOT** automatically create or merge pull requests.
- The agent must **NOT** manage Git repositories on behalf of users.

## Deployment Target
- **Platform**: Gemini Enterprise Agent Platform (Agent Runtime)
- **Session Management**: Handled by Agent Runtime natively.
